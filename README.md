# Maize Genotype-by-Environment Yield Prediction

Our Genomes-to-Fields G×E prediction competition entry, written as a reproducible step-by-step pipeline.

## Context

Entered as team DeepCropVision in the Genomes to Fields Genotype by Environment Prediction Competition. Competition results were published in *Genetics* (2025).

Run in order: `Data_PreProcessing.ipynb` builds the joined feature table, `Hybrid_Features.ipynb` adds genotype hybrid features, then the modelling notebooks follow.

## Notebooks

- `Data_PreProcessing.ipynb`
- `Hybrid_Features.ipynb`
- `Modeling_Script.ipynb`
- `Train_Test_Split_Imputations.ipynb`

## Related publication

- [Genetics 229(2), iyae195](https://doi.org/10.1093/genetics/iyae195)
